# Golf Logbook

Live engine data and trip logging for a 2008 VW Golf 5 1.9 TDI (BLS), through a Bluetooth LE OBD-II adapter (Vgate iCar Pro 2S), in Chrome on Android.

- Drive: an instrument cluster with RPM, speed, boost, coolant, estimated consumption and power.
- Trips: every trip is stored on the phone (IndexedDB) and can be exported as CSV.
- Car: VIN, readiness monitors, fault codes (read-only, never cleared), supported sensors, adapter log.

Built by Claudiu and Claude.
